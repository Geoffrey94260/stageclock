Fonctionnalités

Tout ce dont vous avez besoin,
rien de superflu.

Conçu pour les techniciens de plateau, les régisseurs et les équipes de production live.

📡
Sortie NDI
Diffusez le timer directement sur votre réseau via NDI. Compatible vMix, OBS, Resolume et tous les logiciels NDI.
🎛
Bitfocus Companion
Contrôlez Stageclock depuis votre Stream Deck via OSC (port 5005) ou WebSocket (port 8080). Play, pause, reset, scène suivante.
📺
Multi-écran
Ouvrez la fenêtre output sur n'importe quel écran externe. Redimensionnable, déplaçable, plein écran à la demande.
⚡
Rundown complet
Gérez plusieurs scènes dans un rundown. Ajoutez, réordonnez, supprimez. Auto-avance optionnelle à la fin de chaque scène.
💬
Messages en direct
Envoyez des messages texte qui s'affichent en overlay sur l'écran de sortie. Affichez ou masquez d'un clic.
💾
Sessions
Sauvegardez et rechargez vos rundowns complets en JSON. Tous les paramètres sont inclus dans le fichier de session.

Bitfocus Companion

Contrôle total depuis
votre Stream Deck.

Connectez Stageclock à Bitfocus Companion via OSC ou WebSocket. Toutes les actions sont disponibles en un bouton.

Adresse OSC WebSocket JSON Action
/stageclock/play{"cmd":"play"}Démarrer le timer
/stageclock/pause{"cmd":"pause"}Mettre en pause
/stageclock/toggle{"cmd":"toggle"}Play / Pause
/stageclock/reset{"cmd":"reset"}Remettre à zéro
/stageclock/next{"cmd":"next"}Scène suivante
/stageclock/plus30{"cmd":"plus30"}+30 secondes
/stageclock/minus30{"cmd":"minus30"}−30 secondes
/stageclock/plus60{"cmd":"plus60"}+60 secondes
/stageclock/minus60{"cmd":"minus60"}−60 secondes
# OSC — port UDP 5005
Adresse IP : 127.0.0.1
Port : 5005
# WebSocket — port 8080
ws://127.0.0.1:8080
Format : JSON { "cmd": "play" }
Installation

Opérationnel en 2 minutes.

01
Télécharger l'installeur
Téléchargez le fichier .exe depuis la page GitHub Releases et lancez-le. L'installation prend moins d'une minute.
GitHub Releases ↗
02
NDI — installer NDI Tools (gratuit)
Pour diffuser le timer en NDI sur votre réseau, installez NDI Tools de Vizrt. Utilisez ensuite "NDI Screen Capture" pour capturer la fenêtre output de Stageclock.
ndi.video/tools ↗
03
Bitfocus Companion (optionnel)
Dans Companion, ajoutez un module "Generic OSC" pointant vers 127.0.0.1:5005. Assignez les adresses OSC à vos boutons Stream Deck.
04
Compiler depuis les sources (développeurs)
Node.js 18+ requis.
git clone https://github.com/Geoffrey94260/stageclock
cd stageclock
npm install
npm run dev
